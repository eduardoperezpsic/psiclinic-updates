# PsiClinic para Windows

Desarrollé PsiClinic para organizar expedientes, notas de sesión, agenda, documentos y familiogramas en la consulta psicológica.

**Psic. Eduardo Pérez Cervantes**

## Descargar

[Descargar la última versión para Windows](https://github.com/eduardoperezpsic/psiclinic-updates/releases/latest)

Necesitas Windows de 64 bits. Puedes utilizar el programa gratuitamente.

1. Descarga el archivo que termina en **Portable.zip**.
2. Haz clic derecho sobre el ZIP y selecciona **Extraer todo**.
3. Conserva completa la carpeta y abre **PsiClinic Premium.exe**.
4. Crea tu cuenta y guarda el código de recuperación fuera de la computadora.

La versión portable funciona sin instalador ni permisos de administrador. Windows puede mostrar **Editor desconocido** porque esta edición no tiene certificado de firma digital. Descarga únicamente desde esta página.

## Tus expedientes y respaldos

La información se guarda cifrada en tu equipo, en `%LOCALAPPDATA%\PsiClinic Premium\Datos`. No borres esa carpeta al actualizar.

Usa **Configuración > Seguridad y respaldos > Exportar respaldo** para guardar una copia externa. Sin la contraseña o el código de recuperación no puedo recuperar tu información.

## Actualizar

Abre **Buscar actualizaciones** dentro de PsiClinic. Cuando la descarga esté lista, cierra normalmente el programa y espera a que vuelva a abrirse. Guarda antes un respaldo reciente.
